# Моделювання багатошарового бінарного перцептрона (ББП)

Цей програмний додаток створений для моделювання логічних функцій (AND, OR, XOR) за допомогою багатошарового бінарного перцептрона.

## Частина 1: Основний функціонал
* **Графічний інтерфейс (GUI):** Створено сучасний інтерфейс за допомогою `customtkinter`.
* **Валідація та логування:** Перевірка введених даних, запис подій та помилок у `perceptron_app.log`.
* **Збереження результатів:** Формування та збереження звітів навчання у директорію `reports`.
* **Зовнішня конфігурація:** Налаштування винесені у файл `config.json`.
* **Математична модель:** Власна реалізація ББП (numpy).

## Частина 2: Тестування та усунення дефектів (+fix)
* **Функціональне тестування:** Проведено тестування нормальних, граничних умов та виняткових ситуацій. Складено таблицю тестування.
* **Bug Reports та Fix:** Виявлено та виправлено дефекти, пов'язані з відсутністю верхньої межі для швидкості навчання та системними крашами при введенні тексту замість чисел.
* **Регресійне тестування:** Проведено повторне тестування, яке підтвердило стабільність роботи UI після виправлень.
* **Unit-тестування:** Написано автоматизовані тести (`test_perceptron.py`) для перевірки ініціалізації матриць ваг та математичної функції активації (сигмоїди).
