# Моделювання багатошарового бінарного перцептрона (ББП)

Цей програмний додаток створений для моделювання логічних функцій (AND, OR, XOR) за допомогою багатошарового бінарного перцептрона.

## Реалізований функціонал згідно з вимогами:

* **Графічний інтерфейс (GUI):** Створено сучасний та інтуїтивно зрозумілий інтерфейс за допомогою бібліотеки `customtkinter`, який підходить для недосвідчених користувачів.
* **Валідація та обробка помилок:** Програма перевіряє коректність введених параметрів (швидкість навчання, кількість епох). У разі введення некоректних даних з'являється зрозуміле повідомлення, а програма продовжує роботу без аварійного завершення.
* **Логування:** Усі ключові дії програми та помилки автоматично записуються у зовнішній файл (за замовчуванням `perceptron_app.log`).
* **Збереження результатів:** Реалізовано функцію формування детального звіту після навчання з можливістю його збереження у вигляді текстового файлу в директорію `reports`.
* **Зовнішня конфігурація:** Базові налаштування програми (версія, кольорова тема, шляхи до файлів логів та звітів) винесені у зовнішній файл `config.json`.
* **Математична модель:** Власна реалізація алгоритмів прямого та зворотного поширення помилки за допомогою бібліотеки `numpy`.
